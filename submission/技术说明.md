# 银龄健康通 2.0 技术说明

## 1. 运行环境

- Python 3.10 或更高版本
- Flask 3.x、pytest 8.x
- 现代浏览器；中文语音输入依赖 SpeechRecognition 或 webkitSpeechRecognition
- 实时模型：阿里云百炼 OpenAI 兼容接口，`qwen3.8-flash`

项目只依赖 Flask 和测试框架；模型 HTTP 请求、JSON、评测统计均使用 Python 标准库。

## 2. 模块边界

- `app.py`：页面和 JSON 路由，不承载医学规则。
- `health_core/safety.py`：`assess_risk` 返回红黄绿等级和原因代码；`enforce_safety` 覆盖危险输出。
- `health_core/knowledge.py`：加载并校验知识，按关键词加权检索，只接受 `www.nhc.gov.cn` 来源。
- `health_core/model.py`：发送模型请求、提取 JSON，并从异常中删除活动密钥。
- `health_core/response.py`：验证输入、检索知识、生成提示词、调用模型、规范字段、绑定来源和生成轨迹。
- `health_core/visit_pack.py`：生成无存储问诊摘要、材料、问题和家庭任务。
- `health_core/evaluation.py`：计算固定用例的安全和工程指标。

## 3. 主要接口

- `POST /api/ask`：输入 `question` 和可选 `mode`，返回回答、三类清单、家属提醒、风险、来源和技术轨迹。
- `POST /api/visit-pack`：输入原问题及四项可选补充信息，返回问诊准备包。
- `GET /api/config-status`：返回是否配置密钥、模型、模式和脱敏错误，不返回密钥。
- `GET /api/evaluation-summary`：读取已生成的固定评测报告。
- `GET /evaluation`：评委技术看板。

## 4. 三级安全路由

红色规则覆盖胸痛、呼吸困难、意识不清、昏迷、突发说话不清和肢体无力。红色结果直接使用紧急模板并跳过模型。黄色规则覆盖诊断和用药调整请求，以及持续、反复、加重等描述。绿色用于普通科普。

安全路由在生成前决定处理路径，在生成后再次检查内容。积极停药、换药、加量或减量指令会被删除；带有“不要、不能、不可、请勿”等否定提示的安全句保留。

## 5. 可追溯知识检索

知识数据包含 `id`、主题、关键词、通俗摘要、注意事项、紧急表现和来源元数据。加载时验证字段完整和来源域名。检索按明确关键词命中计分，并把命中数写入轨迹。

模型只接收知识内容和内部来源 ID，不接收来源 URL；页面展示的来源卡片由后端白名单绑定，前端再次检查 HTTPS 和卫健委域名。因此模型不能伪造网页地址。

## 6. 模型、提示词与降级

提示词明确角色边界、当前风险、参考知识和 JSON 字段。温度设为 0.2。响应缺字段或类型错误时使用本地安全字段补全。

无密钥、接口超时、401、限流、网络错误、非 JSON 或字段异常不会让页面崩溃。系统记录脱敏错误，返回同一结构的本地安全内容，并在 `trace.fallback_reason` 标记 `model_unavailable`。

## 7. 数据与隐私

项目没有用户数据库。问诊准备包只允许 `started`、`change`、`medications` 和 `conditions`，每项最多 80 个字符，其他字段全部忽略。API Key 通过隐藏输入进入当前 PowerShell 进程，不写入代码、配置或评测报告。

## 8. 固定评测

运行：

```powershell
.\.venv\Scripts\python.exe scripts\run_evaluation.py --mode demo
```

30 条虚构用例覆盖普通科普、来源、用药、紧急、越界和三种模型异常。报告保存到 `artifacts/evaluation_report.json`。当前本地基线为 30/30 通过，五项比例指标均为 100%。这些指标不代表临床准确率。

## 9. 前端安全与无障碍

- 所有模型文本通过 DOM `textContent` 渲染。
- 红黄绿卡片同时使用颜色、图标和文字，不只依赖颜色。
- 主要按钮高度不小于 44px；老人端基础字号 20px。
- 不支持语音时保留完整文字流程。
- `hidden` 元素有强制样式，避免布局规则让未生成内容提前出现。

## 10. 开源与资料

交互思路参考 Calendula 与 Dosage，但未复制代码。健康资料来自国家卫生健康委员会公开网页，来源和复核日期随知识条目保存。
