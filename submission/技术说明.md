# 技术说明

## 1. 运行环境

- Python 3.10 或更高版本
- Flask 3.x
- 支持现代 JavaScript 的浏览器
- 中文语音输入需要浏览器支持 SpeechRecognition 或 webkitSpeechRecognition

## 2. 模块说明

- `validate_question`：校验问题是否为空或过长。
- `is_high_risk_question`：识别诊断、停药、改药、药量和急症相关表达。
- `_find_topic`：从本地 JSON 知识库按关键词选择参考主题。
- `build_demo_response`：生成可控的本地演示回答。
- `_call_model`：调用 OpenAI 兼容 Chat Completions 接口。
- `_normalize_response`：检查模型字段和数组，异常时使用安全的演示字段。
- `/api/ask`：为网页提供统一问答接口。

## 3. 模型配置

项目默认 `APP_MODE=auto`。没有 `OPENAI_API_KEY` 时返回演示模式；配置密钥后调用 `OPENAI_BASE_URL + /chat/completions`。模型输出要求为 JSON，后端仍会校验字段，不直接信任模型输出。

## 4. 数据和隐私

演示知识保存在 `data/health_knowledge.json`，只包含通用健康教育内容。项目不配置用户数据库，不保存姓名、身份证号、病历号或长期健康档案。

## 5. 开源参考与许可证

交互设计参考 [Calendula](https://github.com/citiususc/calendula) 的服药提醒与记录思路、[Dosage](https://github.com/diegopvlk/Dosage) 的用药跟踪思路。本项目未复制参考项目源代码。两个参考项目均标注 GPL-3.0，后续如直接复用代码，需要遵守相应许可证。

## 6. 风险控制

- 对用户输入做长度和空值校验。
- 高风险问题强制覆盖安全提示。
- 模型调用异常时回退到本地结果。
- 前端使用 `textContent` 渲染模型字段，避免把回答当作 HTML 执行。
- 紧急症状只提示及时急诊，不在页面上给出远程治疗方案。
