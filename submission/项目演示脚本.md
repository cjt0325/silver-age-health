# 银龄健康通 2.0 三分钟现场演示脚本

## 0:00—0:20 开场

“这不是一个替老人看病的聊天机器人。银龄健康通解决的是三个更具体的问题：健康知识看不懂、去医院不知道带什么和问什么、家属无法及时参与。老人仍然只需要说一句话。”

## 0:20—0:55 绿色：可信健康科普

1. 打开首页，点击“怎样预防跌倒”。
2. 点击“帮我讲明白”。
3. 指出绿色“健康科普”卡片、短句解释和就医准备清单。
4. 展示“参考依据”中的国家卫生健康委员会链接。
5. 说明：“来源不是模型生成的，而是后台白名单绑定的。”

## 0:55—1:25 黄色：用药决策拦截

1. 点击“降压药能停吗”。
2. 指出黄色“尽快咨询”和“不要自行作出治疗决定”。
3. 说明：“系统能识别‘停掉一半、把药停了’等自然口语。即使模型返回了停药建议，后处理也会删除并覆盖。”

## 1:25—1:50 红色：紧急规则优先

1. 点击“胸痛呼吸困难”。
2. 指出红色“立即求助”。
3. 说明：“这一类问题不会交给大模型生成居家处理方案，而是由确定性规则直接处理。”

## 1:50—2:20 问诊准备与家属协同

1. 返回跌倒问题，点击“填写补充信息”。
2. 选择开始时间和变化，填写“带着降压药药盒”。
3. 生成准备包，展示给医生的摘要、材料、三个问题和家庭任务。
4. 说明：“这里只使用当前页面，不保存姓名、身份证号或长期健康档案。”

## 2:20—2:50 技术看板

1. 点击“查看系统依据”。
2. 展示模型与模式，强调密钥内容永不显示。
3. 展示 30 条虚构固定用例：30/30 通过，五项比例指标均为 100%。
4. 说明：“这些是可复现的工程与安全指标，不是医学诊断准确率。”

## 2:50—3:00 收束

“项目把大模型放在可控的知识、安全和行动闭环中。AI 不替医生下结论，而是帮助老人更清楚地理解、更充分地准备，也让家属更早参与。”

## 现场备用方案

- 语音不可用：直接点击示例问题。
- 模型或网络不可用：本地模式仍展示风险、来源、清单和准备包。
- 不在投屏画面输入 API Key；提前用 `start_live.ps1` 隐藏输入。
