# 项目现场演示脚本

建议时长：3 分钟。

## 0:00—0:25 开场

“很多老人不是不关心健康，而是健康信息太专业，也不知道去医院前应该准备什么。银龄健康通让老人用一句话或一段语音提问，把健康知识讲成听得懂、能行动的内容。”

## 0:25—1:15 健康问答

1. 打开首页，说明页面采用大字号和高对比度设计。
2. 点击示例“高血压怎么注意”。
3. 点击“帮我讲明白”。
4. 指出回答中的简单解释、日常注意和就医提示。
5. 点击“朗读回答”，说明老人可以少看屏幕、多听内容。

## 1:15—2:05 就医协同

1. 指向“就医准备清单”，说明系统会提醒携带血压记录、药盒和检查报告。
2. 指向“可以问医生”，说明老人提前准备问题后，问诊更有条理。
3. 点击“复制提醒”，展示生成的家属消息：“老人刚刚咨询了……建议陪同记录症状并准备相关资料。”

## 2:05—2:40 安全边界

1. 输入“我能不能把药停了？”。
2. 展示系统不会擅自给出停药结论。
3. 说明系统只做健康教育和就医准备，治疗决定交给医生或药师；胸痛、呼吸困难、意识不清等情况会提示及时急诊。

## 2:40—3:00 收束

“这个项目的重点不是让 AI 替医生，而是让老人更容易理解健康知识，让家属更早知道情况，让一次就医准备得更充分。项目采用轻量网页和 JSON 知识库，没有 API 密钥也能完成完整演示，适合在社区健康教育中继续扩展。”
